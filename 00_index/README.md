# Knowledge Base Index

## Metadata template

Each important item should have a companion Markdown record:

```yaml
---
title: ""
date: YYYY-MM-DD
owner: ""
project: ""
tags: []
status: draft | reviewed | superseded
source: "relative/path/to/original"
---
```

## Categories

- `01_papers`: papers and reading notes
- `02_projects`: specifications, decisions, milestones
- `03_experiments`: plans, results, and failure analysis
- `04_code`: environment, API, and repository guides
- `05_datasets`: dataset cards and preprocessing
- `06_prompts`: reusable prompts and evaluation examples
- `07_faq`: recurring questions and verified answers
- `99_archive`: superseded material
