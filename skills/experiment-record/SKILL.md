# Experiment Record

Use the team experiment template. Record goal, hypothesis, input data and preprocessing, code and data versions, environment, parameters, procedure, results, interpretation, failure analysis, artifacts, and reproduction steps. Distinguish observed results from interpretation and untested hypotheses. Do not overwrite an existing record; create a dated revision or link to the prior version. Update the team index only when requested.

Return a concise record plus missing fields, reproducibility risks, and next actions.
