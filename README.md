# AI Team Knowledge Base

This repository stores the team's papers, projects, experiments, code guides, datasets, prompts, and FAQs.

## Workflow

1. Put new materials in the appropriate numbered folder.
2. Ask Codex to use `$team-knowledge-base` and update the catalog.
3. Review generated summaries and source links.
4. Commit and push the changes.

See `00_index/README.md` for the metadata format.
